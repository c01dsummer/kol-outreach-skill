## P3 试点的回滚与成败判据（source §D.14 / §D.15；第 3 步的验收与 go / no-go 引用它们）

### §D.14 回滚条件（试点本身）

任一命中即撤掉 CI 步骤（保留文件，写 ADR 记原因 —— 业-60）：

- `npm run formal` 在 CI 上 > 30 秒（阈值是本文件自定；`formal` 步只跑一次、不乘变异数 —— 变异只跑验证者 `test` / `selfcheck`，`mutate-rule.ts:58`；秒数只在同一台机器上比，ADR-72），或出现不可重现的结果（探索器是确定性的，出现即 bug）。
- 连续三次「反例」被人判定为模型错而不是代码错。
- 模型核心（不含对拍夹具与打印）超过 350 行（体量线，`size-rule.ts:26`，ADR-80 未动阈值）还表达不了 `8-p3-pilot.md §D.9` 的全部输入。
- 写前记账的开销：用一个 3000 请求量级的基准（不是 selfcheck —— 它的夹具只有十几次请求：cc132a7 读代码所得，d7e20d7 的 `selfcheck.ts` 已从 661 行长到 1305 行，未复数）实测账本落盘总耗时 > 限速总时长的 5%。

### §D.15 试点成功 / 失败判据（第 19 问）

**成功，六条同时成立：**

1. **回归式**：撤掉 `budgetProblem` 的入口校验后 `npm run formal` 的值域扫描变红（I5）；把 `entry-cadence` 场景的 `persistEvery` 设回名单长度后 `SpendIsRecorded` 变红（I2）；拆分后五个场景的可达状态数与最短反例长度与 #75 记录（分支 2deb489 的场景表）一致（TLC 参数钉住）。（「不给反例、让模型自己找到」在构造上不可能 —— 不变量本来就是从反例反推的。）
2. **盲写不变量**：一个没读过 `8-p3-pilot.md §D.0` 与 CE 清单、也没读过 #75 模型的上下文，只依据 P3 原文 + `§D.2` 术语表写不变量，再跑探索器；它写出的不变量里必须有与 I2 同构的一条（探索器报出崩溃窗口反例）和与 I5 同构的一条（由值域扫描报出 —— BFS 模型里 ⊥ 不可表示，I5 不是探索器能报的）。
3. `8-p3-pilot.md §D.2` 的每条义务都有测试认领 + 至少一个变异被抓到；`npm run mutate` 无存活（判定是四态 caught / elsewhere / crashed / survived，`mutate-rule.ts:301`，外加「派出去没结论」硬失败 —— 只有 caught 算抓到）。
4. `npm run check` 总时长增加 < 60 秒（CI 数字；阈值是本文件自定，ADR-82 不管设定值。口径按 ADR-72：同一台机器、预热后量、real / user / sys 都记，首跑与热跑分开（ADR-75 编译缓存）；`formal` 步只跑一次不乘变异数，属性用例那部分乘变异数并按并行度折算 —— 这 60 秒相对 ADR-72 那台 4 核上 mutate 227.8 s 墙钟是什么倍数，要在同一台机器上重量，未实测）。
5. 独立复核（只读需求、EARS、术语表、对应的对外文档、类型签名、`mutate --brief`，不读模型与实现 —— `0-process.md 通-14` 的准入清单）的意见里，「不成立」为零或已处理留痕，**「没资格判断」每条都有去向**（转人批或登记为未知；不要求为零 —— 要求为零会激励把第三档压进第一档；`0-process.md 通-13`；机器评审器的被抑制发现按 `6-INTEGRATE.md` 行 140–149 用替身评论留痕、合并者按行 199–206 逐条找 —— 替身评论是作者写的，不是批准痕迹；4-VERIFY §「红线改动必须过一次独立复核」现在在行 239–269）。
6. `requirements.json` 的 P3 `text` 一字未改；新增判据由一条 ADR 提交、逐条裁决，采纳的每条在那条 ADR 里有独立结论（P3.e 与 P3.f 各自的架构决策另有 ADR，J43 / J44；业-19、业-21、业-22）。

**失败，任一成立：**

- 第 1 条的任一回归不变红。
- 模型报的反例里假的多过真的（试点期内累计计数；§D.14 的「连续三次」是另一条独立的回滚线）。
- 为了让模型「通过」，有人改了 I1–I7 中任何一条（`0-process.md 通-15`：不变量只增不删）。
- 试点超过两个 48 小时周期（本文件自定阈值；分支寿命闸门已撤，ADR-76）还没合进主干 —— 说明切法错了，按本文件的步骤拆得更小。
