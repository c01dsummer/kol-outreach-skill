# 外部增强供应商准入

**当前没有接入任何第三方增强供应商。** 公开指标只使用已有 TikHub key；
不要要求用户配置第二个账号，也不要把公开异常信号描述成第三方假粉审计。

## 接入前必须同时满足

1. 普通个人邮箱可自助注册，当场获得 API key，不要求公司邮箱、公司地址或销售审批
2. 同时覆盖 TikTok 与 Instagram，返回结构化同步响应
3. 公开指标定义、样本量、响应 schema、价格、退款与服务边界
4. 有可核验的法律主体、联系方式和足够的运营历史
5. 能小额购买或试用，并可用一批已知账号做逐字段对照
6. 原始测量带来源与时间；第三方分数只能作为建议，不能单独删除或降级创作者

任一条不满足，就只记在 `docs/data-source-strategy.md` 的调研里，不写适配器、不加环境变量。

## 当前结论

- Influencers Club 与 Click Analytic 要求公司/工作信息，不满足个人开发者可分发约束
- DecodeCreator 服务历史很短、缺少可核验公司主体与独立基准；其派生信号基于公开数据，
  不具备进入正式评分链的证据
- 因此当前实现只保留供应商无关的 `Measurement<T>` 来源结构，不提供第三方入口

以后有供应商通过准入，也必须先做隔离对比：第三方结果只写入结构化记录，不改变分层；
真实样本验证通过并形成新的明确需求后，才能讨论是否进入决策链。
