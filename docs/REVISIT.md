# 回访说明书

> 回访例程照这一份做。例程本体在需求所有者的 claude.ai 账户里，它的 prompt 只有一句「克隆后读 `docs/REVISIT.md` 照做」——
> 规则只在这里，不在 prompt 里，也不在 `.github/` 下（转发文件不装内容）。
> 为什么有它、各条归哪一档：ADR-151。台账本身，以及每一块里定死不改的那两行：ADR-152。

---

## 能写什么

- **只写一处**：在回访台账 ADR-152 末尾追加一块，开一条只改这一个文件的 PR。台账里已有的块一个字不改。
  另外只做一件事：关掉过期的上一条回访 PR（「每次开始」第 3 步）。
- **永不改** `process/`、`scripts/`、`docs/requirements.json`、`.github/workflows/check.yml`，也不改台账以外的任何文件。
- **不替人下结论**：不给任何记录写「采纳」，不标欠条已还，不判死亡条件（ADR-80、ADR-86、ADR-151 第四节第 2 条）；
  不合并、不批准自己的 PR，每一块由需求所有者合（ADR-151 第三节第 5 条）。
- **候选只从本文写明的来源取。** 本文写了几个来源，就只从那几个取；一个都没写时，候选表只有「无候选」一行。
  这一块照样要写，它是心跳。

## 日期、「本跑」与 PR

- **日期**一律取北京时间的当天：`TZ=Asia/Shanghai date +%F`。分支名、块标题、候选 id 都用它。
- **本跑**是这次克隆到的主干提交：`git rev-parse --short=7 origin/main`。
- **一天只开一条**：分支 `claude/revisit-<日期>`；这个分支名的 PR 已经有了，就停下，不开第二条。
- **PR**：标题与提交说明都是「回访台账 <日期>」；正文一句话：只追加了 ADR-152 一块，上周结果是什么，候选几条。
  不开草稿 —— 回访 PR 走 `process/6-INTEGRATE.md`「什么不走这套」，检查绿了直接合（ADR-151 第三节第 5 条）。
- 读 PR 用 REST 接口（`/repos/c01dsummer/kol-outreach-skill/pulls?state=all`）或手头的 GitHub 工具。
  `gh pr` 走 GraphQL，在云端会话里会报 403；它报错不等于读不到。

## 每次开始

1. **核不是浅克隆**：`git rev-parse --is-shallow-repository` 应为 `false`。是 `true` 就 `git fetch --unshallow`；
   做不到，本块里所有要翻历史才得出的值都写 `无从确认：浅克隆`。
2. **找上一条回访 PR**：分支名以 `claude/revisit-` 开头、创建时间最晚的那一条。
3. **定上周结果**，按那条 PR 的状态取一个 token，原样写：
   - 合进了主干 → `已合入`
   - 关了、没合：上面有例程留的「过期」评论 → `例程关闭`；没有 → `所有者关闭`
   - 还开着 → 先关掉它，留一句评论「过期，由 <本块日期> 那一块接替」，再写 `例程关闭`；
     关不掉就写 `无从确认：关不掉 #<号>`，并在本块那条 PR 的正文里点名它还开着
   - 一条回访 PR 都没有 → `无从确认：没有上一条`
   - 读不到 PR：主干台账最后一块的日期在本块日期之前 8 天以内 → `已合入`；否则 `无从确认：读不到回访 PR`
4. **数上一块**，只在上周结果是 `已合入` 时数。上一块 = 主干上 ADR-152 里最后一个块标题之下那一块，
   块标题用 `grep -nE '^## [0-9]{4}-[0-9]{2}-[0-9]{2} · 本跑 '` 找：
   - 提出 = 它的候选行数，「无候选」那一行不算
   - 接受、拒绝 = 那几行「人判」栏里「接受」「拒绝」各几个
   - 不是 `已合入` 时不数，三个数整组写一次 `无从确认：<同上周结果的原因>`

## 一块怎么写

接在 ADR-152 末尾，前面空一行。头两行的写法由 ADR-152 第一节定死，其余照这里：

```markdown
## <日期> · 本跑 <本跑>

- 上周结果：<token> · 提出 <N> · 接受 <M> · 拒绝 <K>

| id | 候选 | 值 | 人判 |
|---|---|---|---|
| <日期>#1 | <一句：是什么、在哪> | <值> | |
```

- **id** 是本块日期加序号，后面的 PR 引一条候选就引这个 id。
- **值**只有三态：查到的值本身、`没查到`（查了，没有）、`无从确认：<原因>`（查不了）。缺的值不留空，也不写成 0。
- **人判**例程永远留空。需求所有者合并前可以在候选行上填「接受」或「拒绝」，不填就是没判。
- **没有候选**就只写一行 `| — | 无候选 | | |`；这一行的「值」与「人判」空着是格式本身，不算缺值。
- **候选那一句**不写「重启条件」紧跟冒号，也不写加粗的「什么条件下……」紧跟冒号 —— 欠条台账从 `docs/adr/` 里按这两种写法抽条件，
  照抄进台账就多出一张假欠条。要提条件，写「条件是……」。
