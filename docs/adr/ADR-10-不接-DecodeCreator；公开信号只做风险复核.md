# ADR-10 不接 DecodeCreator；公开信号只做风险复核

- 日期 · 2026-08-26 · 外部增强供应商复查
- 类型：**事实证伪**
- 冲击的需求：P1、P5、F5；新增 D8、D9、F8、U7
- 结论：**采纳** —— 撤回将 DecodeCreator 作为正式增强源的候选结论

### 触发它的事实

用户实际尝试后确认 Influencers Club 与 Click Analytic 都要求公司/工作信息，违反本仓库
“普通个人拿到 repo 就能注册运行”的分发前提。继续搜索时，DecodeCreator 表面上满足普通
Google 登录与双平台，但进一步核验发现：

1. [官方 About](https://decodecreator.com/about) 说明服务由印度的一名独立开发者运营，
   数据来自 HikerAPI、tikwm 与 YouTube API 后再做派生分析；联系渠道是 Gmail
2. [服务条款](https://decodecreator.com/terms) 明确派生信号不保证准确，99.5% 只是目标而非保证
3. [.com 注册局 RDAP](https://rdap.verisign.com/com/v1/domain/DECODECREATOR.COM)
   显示域名创建于 2026-07-14，核验时只有约六周历史
4. 未找到可核验公司主体、独立基准、客户案例、状态历史或第三方评测

这些事实不能证明它是骗局，但足以证明仓库没有资格让它的分数改变 KOL 排名。

### 结论与连带改动

- 不新增 DecodeCreator key、适配器或任何供应商专属评分字段
- 原来的 `fake_follower_score` 仅保留为旧任务兼容字段，分层明确忽略
- 用 TikHub 主页近期作品计算透明的公开指标；只能称“受众质量风险”，不能称假粉率
- high 至少需要两个同行异常信号，只降一级人工复核，永不自动删除
- 不新增不透明 KOL Weight；现有 score 权重不变
- KOL Rate 拆成公开互动率与明确合作报价；缺报价不自动估价
- 第三方准入改成主体、个人自助注册、双平台、方法/schema、历史与小额实测全部通过

### 教训

**“有价格页、能点注册”不等于可进入决策链。** 数据供应商有两道门：第一道是能不能用，
第二道是它有没有资格影响用户花钱。前者只需验证注册和接口，后者还需要主体、方法、历史与
可重复基准。以后调研必须把两道门分开记录。
