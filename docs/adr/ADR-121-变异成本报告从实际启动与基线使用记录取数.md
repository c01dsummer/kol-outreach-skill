# ADR-121 变异成本报告从实际启动与基线使用记录取数

- 日期：2026-09-27 · 长期维护变异配置与验证成本时
- 类型：需求有歧义
- 触发它的事实：ADR-120 与公开验收已决定独立交付实际组合使用、基线复用及经过时间报告，但尚未定义实际启动、成功、额外复用和观测缺失的计量资格。
- 冲击的需求：不改变业务需求；补充 `process/4-VERIFY.md` 的成本报告公开验收，保持 P1–P5 的既有保障。
- 结论：采纳
- 理由：配置数量与实际启动不是同一个量；缺观测若补零，报告会把未测到包装成成本为零。复用与计时必须取真实执行记录，只提供判断原料。
- 连带改动：`process/4-VERIFY.md`、`docs/ARCHITECTURE.md`、`docs/SYNC.md`；既有 `mutate.ts` 负责观察，`jobs-rule.ts` 负责纯汇总和呈现。

## 决定

公开详细验收先写进 `process/4-VERIFY.md`，不以实现输出反推统计定义；
可比成功证据仍用 `process/6-INTEGRATE.md` 的既有要求，不增加固定秒数闸门。

报告按本次实际路由列每个验证者与组合，配置使用数与实际使用者分开。
本次复用身份沿既有 `by` 与排序后的 `only`；缺 `only` 为全量，
选择组、依赖闭包及执行顺序从冻结的 `RouteSnapshot` 投影，不再手写归组表。
全量、选组及不同验证者分别保留；零使用和观测未知的配置行不删除。

协调者只从真实启动记录数正常基线，经既有 `baselineFault` 确认完整断言全绿才记成功，
记录成功基线身份并关联使用该配置的变异。额外复用按每份成功基线的真实使用者计，
第一次使用不算，后续每次加一；无人使用为零，关联未知不从配置条数推断。
worker 以实际 spawn 事件观察启动，结果新增可选 `started` 供成本汇总；
缺该字段或缺结论只表示成本未知，不改变旧变异判定、退出码或收尾。

正常基线和变异各列实际经过时间及观测资格，不为报告重新跑基线。
未施变不计时间；真实测得的零合法，缺计时不补零。
合法点名早停保留原 `caught` 资格；失败、未完成、缺回报不能替成功样本作提速证据。
逐次经过时间相加只声明其观测范围，不冒充 CPU、job 或完整检查耗时。

版本包含可信 Git 的 base/head、现有 live fingerprint 的待验源码身份、
变异目录与依赖锁指纹、命令、Node/平台/架构及生效并行配置。
运行完整性和成本观测完整性分别声明；身份或观测取不到，明确无从确认及原因。

维护报告可先按已有变化分类给数量和路由差异，再分节列配置、依赖与顺序变化。
摘要与完整清单使用同一份原料，完整变化和完整组合行保留，不替评审者挑“重点”。
本次修改触发 ADR-120 末尾呈现欠条；代码验收完成后只在该记录末尾追加兑现说明。

## 边界

全量正常基线属于外层完整检查，当前报告未观测其启动、成功、复用和经过时间，
这些量声明未观测，不能写成零，也不能由外层运行完成倒推已测得。
其余已取得观测可以列为部分原料，不据此声称整份成本证据完整或可比。

不改变可信 Git 比较、全量解释、实际选组、正常基线资格、断言归因、
夹具/进程错误记号、合法主动停下、进程收尾或完整运行认领。
不增加业务 API、新命令或性能通过判定；不新增目录或持久历史统计表。
报告的数字形状与计算可验证，解释语义和成本是否可接受仍由评审者判断。
本记录先于实现登记，不声称报告已验收，也不声称已取得提速收益。

## 真实成本入口接入与独立验收（2026-09-28）

纯统计与启动字段协议均合入后，从 main `16714601fb378b474c1b6d8e90bf1911f62f14dd` 接入真实观察。
正常基线以实际 spawn 起计，经既有完整成功判据确认后才关联真实使用者；worker 的实际启动信息穿过现有协议。
源码、目录和锁在首次正常基线与施变之前冻结，报告记录实际 Node 命令及生效并行配置。
普通收尾等待同一摘要的人读行和单行 JSON 写完；brief 与 worker 不输出成本段，早期可捕获拒绝只报告 unavailable。
全量正常基线仍在外层，启动、成功、复用与时间保持未知；报告不增加通过闸门，不改既有施变归因、清理或认领。

独立作者只读公开合同、类型和签名，事前冻结自有微型仓库案例；不读实现、旧测试、生产变异正文或运行结果。
真实自检组包含十四个静态具名调用：正常执行十三个，另一个是明确的夹具失败槽；串行与双 worker 均完整成功。
普通评审修正两处验证资格：产品坏 JSON／结构落到产品断言，而 observer／driver 故障独立；计时上界取真实 spawn，
夹具在启动前加入一百毫秒延迟，使误把该区间计入验证者时间的错误可被区分。修正不从输出改写 toy 契约或手算口径。
实际受控反例分别删除报告、损坏 JSON、写坏行结构、取消基线关联、借 HEAD 作源码身份、提前起计、丢启动字段、跳过基线、伪报观测完整；
九种均由预定的具名断言拒绝，无夹具或进程故障冒充。既有维护比较与认领恢复入口案例也通过。
这些受控反例不进入生产变异目录，不认领业务判据、不登记豁免，也不解除检查基础设施自我施变的隔离限制。

本次未迁移变异，清单仍为 771 条；实际路由和完整检查结果须由该版本的成功运行核实。
上述入口案例证明接线资格，不是完整 CI 提速样本；不据此报告收益、中位耗时或十五分钟目标已达成。
