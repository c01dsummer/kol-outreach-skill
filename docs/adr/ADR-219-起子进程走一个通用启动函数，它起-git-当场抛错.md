# ADR-219 起子进程走一个通用启动函数，它起 git 当场抛错

- 日期 · 2026-11-18
- 类型：检查（运行时拒绝）加挪文件，是「调 git 只走一个入口」的第二片
- 触发它的事实：ADR-217 定了「只有登记过的文件能直接碰起子进程的模块」，第四节留了「运行时拒绝」不在那条里。主干 `46b1cd7` 上「待挪」27 个文件，其中 11 个只起 node、bwrap、echo 这类程序，从不起 git，它们缺的只是一个不碰模块也能起进程的地方
- 决定人与时间：需求所有者丸子 2026-11-17 18:03Z 在「把 #471 的教训落进两层规矩」线程里选「改成按模块拦，加运行时拒绝」；本条是其中「加运行时拒绝」那一半
- 结论：采纳。人批痕迹：需求所有者合入本条那条 PR
- 理由：「禁用接口」的另一半 —— 口外不许直接碰，口里要有个能用的口。真要起进程的那一刻，程序名是确切的值，判它是不是 git 不用猜；经 shell 起时起什么要读懂命令串，所以干脆不让经 shell
- 连带改动：`scripts/check/start-process.ts`（新，通用启动函数）· `scripts/check/launch-count.ts` 认 git 改用通用启动函数里那一个 · 11 个文件的导入改指通用启动函数 · `scripts/check/child-process-registry.json`（「登记」加通用启动函数，「待挪」删 11 行）· `scripts/test.ts` 一组新测试、观察器运行器那条软链测试多拷一个文件 · `scripts/check/mutations.json` 本条的变异，启动数那两条变异跟着代码挪 · `docs/ARCHITECTURE.md` 一行 · `docs/GLOSSARY.md` 一条 · `docs/SYNC.md` 一行

## 一、要用到的事实，各找谁要（`process/3-BUILD.md` 第 8 条）

| 要用到的事实 | 找谁要 | 给机器读的还是给人看的 |
|---|---|---|
| 这一次要起的是不是 git | 调用时传进来的程序名，取路径末段（`/` 与 `\` 都切），是 `git` 或 `git.exe` | 机器（真值，闭集） |
| 这一次经不经 shell | 不问：选项里的 `shell` 一律改成 `false` | — |
| 计数预加载、观察器预加载换掉的函数还拦不拦得到 | 通用启动函数在调用时才从模块对象上取函数（不在加载时存一份），预加载换掉的就是这个对象上的函数 | 机器（Node 的模块对象） |
| 一个文件挪干净了没有 | ADR-217 的闸门：文件里不再写出模块名，「待挪」里那一行就得删 | 机器 |

## 二、通用启动函数做什么

包 `spawn`、`spawnSync`、`execFileSync` 三个，形状与 Node 的一样，其余参数原样转：

1. 程序名末段是 `git`、`git.exe`：当场抛错，不起进程。
2. 选项里的 `shell` 一律改成 `false`，没给选项的补上；选项写在第二个位置（没有参数数组）时也一样。
3. 子进程对象等几个类型从这里再导出，挪过来的文件不用为了类型再去碰那个模块。

`exec`、`execSync` 只能经 shell，`fork`、`execFile` 这批文件用不到，都不包；要用时再加，加的时候照样拦 git、关 shell。

`launch-count.ts` 数启动次数时认 git 改用这里的同一个判法，不另写一份。

## 三、这一片挪了哪些

「待挪」里不起 git 的 11 个：观察器运行器，CI 墙钟两份、预编译三份、实际路径、懒加载 TypeScript、记忆复核、工人输出清理与守护的契约测试。它们原来就只用 `spawn`、`spawnSync`，导入改指通用启动函数就挪完了。几份文件里写在字符串里的模块名（运行时落成文件再跑的代码）不是「模块名这个字面量」，闸门不记。

剩下 16 个都起 git，等 git 入口那一片一起挪。

## 四、拦不住的

- 还在「待挪」里的 16 个文件直接碰模块，不经通用启动函数，它们起 git 这里管不到；等它们挪完才全。
- 「登记」里的文件直接碰模块，不经通用启动函数（计数与观察器两份预加载、预编译父进程、闸门判定），靠评审读理由。
- 经别的程序转一手：起 `sh`、`env`、`npx`、`bwrap` 再由它起 git。通用启动函数只看本进程直接起的那个程序；列一张「会转手的程序」名单是替代读的手写表，不建。
- ADR-217 第三节说的软链或改了名的 git、`git-upload-pack` 这类 git 自带程序、大小写不敏感文件系统上写成 `GIT`：只看名字，认不出。

## 五、它替代什么、什么时候撤

**替代的是「跑」**（`process/README.md` 第二层「一道闸门该不该建」）：判的是调用时的真值，`git` 与 `git.exe` 是闭集，没有一张会随仓库变旧的名单。

> **什么条件下撤**：git 入口那一片挪完、「待挪」清空以后，连续十条改过 `scripts/` 的 PR 里这一句一次都没抛过 —— 那时拦 git 的活已由「只有 git 入口碰得到」接住，这一句可以删；删之前先看 ADR-217 第三节那几类绕法是不是已经另有人管。
