# ADR-120 变异全量解释与分组变化由真实基线核对

- 日期：2026-09-27 · 长期维护变异执行成本时
- 类型：发现更优解
- 触发它的事实：现有选组选取与正常基线复用已接入变异命令，但新增全量、选组回退和组配置变化尚缺统一的版本间说明；历史性能记录不能替每次改动证明当前成本。
- 冲击的需求：不改变业务需求；P1–P5 的既有测试与变异保障保持。
- 结论：采纳
- 理由：从真实 Git 版本抽出变化属于机械核对；为何需要全量、何时值得重审属于阅读判断。两者接在现有变异命令里，避免新建一份会漂的路由表或用解释降低验证资格。
- 连带改动：`process/4-VERIFY.md`、`process/6-INTEGRATE.md`、`docs/ARCHITECTURE.md`、`docs/SYNC.md`；既有变异命令与 CI 传入可信基线。

## 决定与边界

公开验收在 `process/4-VERIFY.md`「选组与全量执行的长期维护」，评审证据在
`process/6-INTEGRATE.md`「改验证成本时,评审要看到实际变化」。不改需求登记表或其渲染。

维护比较使用可信 Git 基线的变异目录与验证者实际配置，复用当前 `kills` 归组路径。
已有未解释全量变异只有核心正文未变时才自动兼容，兼容来自旧 Git 内容，不手写历史名单。
解释存在与否、形状是否完整由机器核；理由及重审条件是否成立由评审者读。
旧提交或旧配置读不出来时失败，不把未知记为没有变化。

本次维护输出列出路由与分组配置变化。实际组合复用数与经过时间报告决定为下一条独立交付，
在本次合入之后再接入；本次不声称已具备成本报告，不以同文件叠分支提前接入。
不建固定秒数闸门；高频验证工作改变时，评审核有限的可比成功证据。
本记录不声称已测得提速，也不以历史短集收益代替本次完整执行资格。

解释不改全量或选组的实际执行、正常源码基线、断言归因、错误记号、进程收尾或审计认领。
本次不新建目录、不提交原始响应或运行产物，不扩展采集能力。

## 死亡条件

若实际执行路径已取消全量回退，变异目录也从结构上拒绝所有无法具名归组的条目，
且可从可信版本比较和完整成功运行核实全量执行集合为空，重新评定并撤除 `full_run` 的形状闸门。
不能仅因全量变少、运行变快或解释太麻烦撤除。

组配置变化清单和另交付的实际复用、计时输出只提供原料，没有额外的性能通过判定；固定秒数闸门本次已判为不建。

## CI 输入通道的核对（2026-09-27）

GitHub runner 已提供事件文件与事件名；直接读取 PR 的 `pull_request.base.sha` 或 push 的
`before`，无需额外修改 workflow 来传递同一份事件起点。缺事件、错形状和错事件字段明确失败，
显式基线仍优先，且所有起点都必须通过真实 Git 祖先资格。原 main/PR 工作流与完整检查链保留。

## 真实入口夹具的执行归属修正（2026-09-27）

主执行者核过迁移前的两次成功运行：PR215 的 `669afd2`，CI `36285153580`，
Node `22.23.2`、4 workers，完整 check 为 27:58；main 的 CI `36281534591` 为 20:27。
两次正常基线约 2:22、独立自检约 4:03，接近；需求测试变异逐条经过时间之和为
2194→3928 秒，自检变异之和为 1088→1095 秒。集合是 main 720 条、PR 734 条，
这些相加值不是 CPU 或 job 耗时，每版只有一次样本，不报中位数或因果收益。

新真实入口夹具放在需求测试，使 80 条旧全量需求变异实际重复执行该夹具。

修的是本改动引入的重复工作，仍在当前 PR 追加，不另开叠分支，也不接入另行交付的成本报告。

上述成功 CI 只验收迁移前版本；迁移后须重新通过完整 CI，当前不声称已验收或已取得提速收益。

## 入口夹具的 Git 环境隔离（2026-09-27）

第二轮评审指出，夹具虽切到临时目录，父进程的 Git 仓库定位变量仍可改变 Git 与验证子进程
实际使用的仓库。采纳仅针对新增入口夹具的修正：两条子进程路径共用环境整理，剥离
`GIT_DIR`、`GIT_WORK_TREE`、`GIT_INDEX_FILE`、`GIT_OBJECT_DIRECTORY`、
`GIT_ALTERNATE_OBJECT_DIRECTORIES`、`GIT_COMMON_DIR`；其他继承环境与显式覆盖保持，
显式 `undefined` 仍表示删除，Git 配置隔离设置保持。

验收用自有临时路径污染上述父环境，真实核对 Git 指向、入口完整施变与恢复；
父环境须在 `finally` 恢复。原入口断言保留，不扩展到既有其他夹具或生产入口。

该反例的 Git 根按目录身份比较：期望从事先创建的夹具目录经 `realpathSync` 推导，
不从 Git 输出反推；规范观察路径后比较，避免把 macOS 临时路径的 `/var` 与 `/private/var`
别名当成不同仓库。此前路径字面量假设过强，修正测试假设，不改实际隔离要求。
