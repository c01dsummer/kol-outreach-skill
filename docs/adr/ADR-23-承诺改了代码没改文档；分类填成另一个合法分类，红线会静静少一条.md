### 一、代码改准了，两份文档还在说旧话

ADR-22 把 collect 那句无条件的「续跑不会重复花费」改成按实际剩余关键词说话。
但同一句承诺还写在两个地方，**都没跟着改**：

- `docs/ARCHITECTURE.md` 的缝隙契约：「修好后 `--resume` 不产生任何新请求」
- `skill/SKILL.md`：「让用户修好文件再 `--resume`，零额外花费」

第二处最要命：**`SKILL.md` 是 Agent 读的**。代码会如实说「还有 N 个关键词
没跑完，续跑会继续花钱」，而 Agent 照着 `SKILL.md` 向用户转述「零额外花费」。
**用户拿到的是那句错的**，因为他听 Agent 说话，不看 stderr。

修了两处文案，并且给同步表加了一行：**改给用户看的报错里的一句承诺，
要改复述同一句话的每一份文档** —— 尤其是给自动化执行者的那一份。

这一条的形状不是「忘了同步」，而是：**代码里的一句话和文档里的一句话是同一个
承诺的两个副本，而只有一个副本有测试。**

### 二、分类填成另一个合法分类 —— 红线会静静少一条

ADR-21 加了「分类必须在分类表里」。但**填成另一个已声明的分类**照样通过。
把 `P4` 的 `cat` 改成 `"D"`：两个值各自合法，于是：

```
✓ P4  D  测试✓ 变异✓  引用 10 处
红线 4 条 · 有测试 4 · 有变异 4 · 显式豁免 1
✓ 审计：红线全部有测试且被变异验证
```

**审计报出「红线 4 条」，然后说全部通过。**

而下游全都按 `cat` 分流：`renderTables` 把 P4 挪进数据那一节，
`audit.ts` 的红线集合是 `cat === 'P'` 算出来的 —— 于是「每条红线必须有测试
和变异」这条硬要求，从此不管 P4。`SPEC.md` 的散文还写着「红线为什么是这五条」，
而表里只剩四条，**没有任何检查会发现这件事**。

修法：编号前缀必须与分类一致（`^{cat}\d+$`）。这条规矩也写进了
`process/1-REQUIREMENTS.md` —— 它是通用的：只要下游按分类分流，
分类填错就等于把需求换了一类。

### 教训

**「值是合法的」和「值是对的」之间，隔着一整类事故。**

ADR-21 那一轮我加的是「分类必须存在」——它挡住了拼错，挡不住填成另一个
真实存在的分类。同一个形状这轮出现了两次：

- 分类 `D` 是合法的，只是不该是 P4 的
- 「零额外花费」是一句合法的中文，只是不该在有剩余关键词时说

所以对每一个「必须是合法值」的校验，还要再问一句：
**一个合法但错误的值会造成什么？** 如果答案是「下游会静默换一条路走」，
那这个校验就只做了一半 —— 它得再回答「这个值和别的什么必须对得上」。

第一条另记一句：**一句承诺在代码和文档里各有一份副本时，只有代码那份有测试。**
文档那份靠人记得，而这轮证明了记不住 —— 尤其当那份文档是给另一个执行者
照着转述的，错的那份会比对的那份更早到达用户。

### 追记 · 同一句承诺的第三份副本 —— 按记忆去搜，搜不到不等于没有

- 第九轮自动评审 · 类型：**事实证伪**（本条立的同步规矩，我自己执行时漏了一份）

上面第一条改了两份文档，并给同步表加了一行「改给用户看的报错里的一句承诺，
要改复述同一句话的每一份文档」。这一轮发现还有**第三份**：`README.md` 里写着
「修好后 `--resume` 不产生新请求」。

漏掉它的原因不是忘了规矩，是**执行规矩的方法不对**：我按自己记得的措辞去
grep（「不产生新的请求」），而 README 那份写的是「不产生新请求」——
**少一个字，搜不到。**

规矩是对的，方法是错的：

> **按记忆去搜副本，搜不到不等于没有。** 同一句话在不同文档里会被不同的人、
> 在不同的时候、用不同的措辞写下来，而搜索匹配的是字面。

修法：README 那句改成有条件的说法（与代码、`ARCHITECTURE`、`SKILL.md` 一致）；
两张同步表里那一行**从「每一份文档」改成点名的清单**，并写明
「点名逐个过，不要 grep」。清单是有限的，记忆不是。

连带改动：`README.md` · `docs/SYNC.md` · `process/2-CHANGE.md`

**一条同步规矩要能被执行，就得给出「要看哪几份」，而不是「所有相关的」。**
「复述同一句话的每一份文档」听起来完整，实际执行时会退化成「我搜得到的那些」。
把它换成一串点名的路径，执行方式就从**回忆 + 搜索**变成**逐个打开**——
后者会漏的唯一情况是清单本身没更新，而那是新增文档时就该做的事。
