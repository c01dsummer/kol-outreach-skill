# ADR-119 合法选组正控制失败时保留需求测试汇总

- 日期：2026-09-26 · 新入口测试与既有工具变异交叉验证时发现
- 类型：实现方便（测试收尾纠正，按 CONVENTIONS 第八节举证）
- 触发事实：M-H7-b/c 已使原断言失败，新增组的合法选组正控制也失败；初稿随后抛错，遮住父套件的失败汇总。独立小范围输出经既有判定器判为 crashed
- 冲击的需求：harness 既有的断言累计与末尾汇总契约；产品需求登记表不变
- 结论：采纳
- 理由：合法对照未完成已经由断言记录失败；额外抛错把真实断言失败变成进程故障
- 连带改动：正控制失败后返回当前组，停止后续拒绝判定；仍执行 finally，父套件继续累计并输出失败汇总

expected、步骤名、完成行、断言标签及原变异元数据不变。进程崩溃、超时、夹具故障、认领变化和资源残留仍拒绝作为指定断言的功劳；正控制失败不执行指定拒绝断言。

上述判定来自独立小范围输出核验，不作为完整变异集合的验收结论。

修订后，完整正常需求测试通过；保留原顺序与原验证配置的 M-H7-b、M-H7-c、M-H42-j 小范围运行全部被抓到。两条旧变异保留原断言失败与末尾汇总，未执行指定拒绝断言；新增变异仍只使指定拒绝断言失败。实际完整测试生成的认领字节在后续变异运行中保留，源码和完整清单逐字恢复。这些是局部兼容证据，没有验收包含新增入口负片的完整变异集合，也不作为 CI 提速样本。
