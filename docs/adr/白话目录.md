# 决策记录白话目录

> 每份决策记录一行白话，原文不动。想知道某份记录说了什么，先看这里；要细节再点进原文（索引见 [README.md](README.md)）。
>
> - **定了什么**：这份记录拍板的事，一句话。
> - **对用户有什么影响**：对用这个 Skill 找博主、出名单的人，有什么看得见的变化。只改开发流程或检查的，写「无（只影响开发流程）」之类。
> - **还欠什么**：这份记录里登记了、还没还上的问题（欠条），挑要紧的说；「已挪到 ADR-xxx」是说那张欠条现在记在那一份里。「已重挂」是说那张欠条的提醒响过、没还，改了提醒条件，仍然欠着。这一栏是 2026-11-22 照原文里的已还、已重挂记录读出来的快照，**以原文为准**：之后欠条还上时，没有机器提醒来改这一格（ADR-236「还欠什么那一栏没有机器跟着改」）。
>
> 新加一份决策记录时，同一条改动里在这里补一行；`npm run adr` 会核每份记录都有一行、没有多出来的行、四格都填了。写得白不白、说得对不对仍靠人读（白话规矩见 `docs/GLOSSARY.md` 与 ADR-207）。
