## 一、事实

1. **哪里原样写出。** `scripts/lib/csv.ts` 第 4–7 行的 `esc` 只在值含 `"`、`,`、`\n`、`\r` 时整格加引号、内部引号写成两个，别的值原样写。`writeCsv`（第 10–13 行）对每一格调 `esc`。`scripts/render.ts` 第 125 行写 `kol.csv` 走的就是它。
2. **谁的字会进格子。** `scripts/lib/rows.ts` 第 5–16 行的列里，`nickname`、`bio`、`best_post_desc` 是博主自己写的；评审名单追加的 `observed_content`、`mismatch_risk` 等列（第 20–27 行）装的是 Agent 的判断，按 #359 的写法会原文摘进博主的话。博主在简介里写一句以 `=` 开头的字，`kol.csv` 里那一格就以 `=` 开头。
3. **会被当成公式。** 这是公开的已知问题（OWASP「CSV Injection」页）：表格软件打开 CSV 时，格子开头是 `=`、`+`、`-`、`@`，或以制表符、回车开头，会被当成公式算；引号是 CSV 的语法，不能挡住它。通行的做法是在这种格子前加一个 `'`。**本条没有实测**：本仓库所在环境出不了网，没有当场核那一页原文，也没有 Excel 或 Numbers 可以打开文件看。
4. **XLSX 本来不会。** `scripts/lib/xlsx.ts` 第 108 行把文字格写成内联字符串（`inlineStr`），不写公式元素，所以 `kol.xlsx` 里以 `=` 开头的格子是文字。HTML 报告不是拿表格软件打开的，本条不涉及。

## 二、裁决

1. **加在哪。** 只改 `writeCsv`：每一格先过一道「可能被当成公式就在格首加 `'`」，再交给 `esc`。顺序是先加 `'` 再转义，所以 `=a,b` 写成 `"'=a,b"`，单引号在引号里面（D5.c）。
2. **哪些开头。** `=`、`+`、`-`、`@`、制表符、回车。需求所有者的决策卡上写的是前四个；后两个照第一节第 3 条的通行做法一起加，是实现者的决定，PR 正文列在「合入即认可」里。
3. **只管文字。** 值是 JS 的数（`score`、粉丝数等）时不加：数不会被当成公式。写成文字的纯数字（可带一个正负号和一段小数，比如 `rows.ts` 第 143 行用 `toFixed(1)` 写出的 `days_since_last_post`）也不加：它在表格里本来就是数，加了 `'` 反而变成文字，排序、求和都会错（D5.d）。别的以 `-`、`+` 开头的文字（`-x`、`+1 555`）照加。
4. **不管什么。** `esc` 本身不变：人工反馈模板（`scripts/lib/manual-feedback-template.ts` 第 33 行）直接调 `esc` 写 `round_id`、平台和账号，读回时（D23）要逐字认得出原值，加了 `'` 就对不上。那几格是本项目自己的标识，不是博主写的字。格首是空格、全角符号等别的写法，本条不管，也没有实测它们会不会被当成公式。
5. **机器读 CSV 的人看到什么。** 这几格多一个 `'`，格内其余的字一个不改。要原值的，读 `kol.xlsx`，或在 CSV 里去掉「后一个字是上面六种之一」的那个格首 `'`。`skill/references/output-format.md`「转义」一句写明。

## 三、交点

1. **P2（红线）。** `outreach_draft` 也走 `writeCsv`。D5.c 只在格首加一个字，格里的 `{…}` 占位符一个不删不改，P2.b 照旧成立。交点声明在 D5，测试认领。
2. **U9.e、U9.g 的「原值」。** 它们要 CSV/XLSX 的评审列取投影原值。本条之后，CSV 里以上面六种开头的文字格多一个 `'`；XLSX 与 HTML 仍是原值。这是需求所有者的取舍（第一节第 3 条的风险换机器读的那一点不便），以 D5.c 为准。交点声明在让步的 U9，测试认领。
3. **P1。** `未查询`、空白、`0` 都不以那六种开头，三态渲染（P1.e）不受影响。

## 四、没选的

- **CSV 原样，交付时提醒用 xlsx 打开**：不改需求，但有人直接用 Excel 打开 `kol.csv` 时风险照旧。需求所有者没选。
- **格首加制表符**：同样多一个字，而且是看不见的字，比 `'` 更难发现。
- **写成 `="…"`**：那本身就是一个公式，只是换了一种算法。
- **只处理 `bio` 一列**：`nickname`、`best_post_desc`、评审列都会装博主的字，列表还会再加列；放在 `writeCsv` 一处，新加的列自动带上。
