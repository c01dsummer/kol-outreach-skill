> 驳回尤其要记 —— 同一个提议会反复出现，尤其当实现者是每次从零开始的 AI。
> **一条驳回记录的价值，和它被引用的次数成正比。**

## 一条记录 = 一个文件

文件名 `ADR-<编号>-<标题>.md`，第一行是 `# ADR-<编号> <标题>`。
两处编号必须一致，`npm run adr` 会验；下面的索引由它生成，**勿手改**。

装在一个文件里的时候，ADR 是这个仓库最大的冲突面 —— 它在语义上追加、
彼此独立，本该是最不该冲突的东西。三条在途分支各自把整册从 537 行写到
1978~2539 行，而且编号互相交错：第一条合进主干之后，后两条不是「追加到末尾」，
是往文件中间十几个位置插入。

换成文件之后，**并发抢号变成文件名撞车**，git 当场报冲突，而不是静默交错。
还有一个更要紧的后果：ADR 不依赖任何代码，于是它**可以先于实现单独合进主干** ——
一个改动里最大的那块因此不必再挤在代码的 PR 里。

**编号允许有空号。** 号一旦用过就不复用，包括那些活在别的分支上、还没合进来的。

写什么、怎么分类，见 `process/2-CHANGE.md`。
