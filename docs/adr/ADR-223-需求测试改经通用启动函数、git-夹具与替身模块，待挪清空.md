## 二、做了什么

1. **起进程的替身（`child-process-stand-in.ts`，登记）。** 测试要看「交没交给 Node、交了什么」，得换掉模块对象上的函数。以前需求测试自己拿着模块对象换，现在拿模块对象的只有这一处，交给测试的是三种用法，都在进入时记下原函数、在 `finally` 里换回（body 还 Promise 的，等它了结再换回），交回 body 的结果；名字只认起进程的七个函数，别的当场抛错：
   - `withStandIns(替身, body)`：换上调用方给的替身。替身拿不到原函数，被叫了也不真起进程。
   - `withSpies(名字, body)`：换上探子，记下每次收到的参数，再原样转给原函数；交给 body 的只有记下的参数。
   - `withRestore(名字, body)`：只记下原样、跑完换回；body 里被测的代码自己去换（自检记当前目录那一处）。body 只问得到「这个名字现在换成了什么」，还没被换的问出 `undefined`。
   换回后再调一次 `syncBuiltinESMExports`：被测的代码若让按名字导入的绑定一起换了，也一起回来。body 还 Promise（或别的带 `then` 的对象）时交回的是一个了结得一样的新 Promise，不是 body 还的那一个。
   只许一段套一段地用：模块里记着正在换着的几段，先了结的那段若不是最后换上的（`Promise.all` 里并排两段就会这样），它当场抛错，但不马上换回，只记「已了结」，换回推到后一段了结时从后往前一起做 —— 马上换回的话，它会拆掉后一段的替身，后一段再换回时又把它的替身装回模块上，漏到后面的组（独立复核实测到；只抛错不留换回的第一版，CodeRabbit 第一轮指出同样会漏）。两段都了结后，模块上回到原样。替身要是函数；探子不探 `exec`、`execFile`，它们自带的 promisify 版本探子带不过去，promisify 出来的形状会变。
2. **需求测试。**
   - 起 node、`ps` 等程序：两处静态导入、五处动态导入改从通用启动函数导入（第六处只在变异维护那组建玩具仓库用，整句删了，并进下一条的 git 夹具）。
   - 在临时目录建玩具仓库、造提交：十一处小函数改经 git 夹具。夹具的三张白名单一项没加：原先用到的 `git mv`、`git rm` 改成先用文件接口挪、删，再 `git add -A`；原先在玩具仓库里问 `diff`、`status`、`ls-tree` 的读，改经 git 入口（与被测的判定真问的同一张表）。
   - 问本仓库受控文件有哪些：改经 git 入口的 `ls-files -z`。
   - 找 PATH 上的 git（给假 git 包一层用）：原先起 `sh -c 'command -v git'`，改成逐个查 PATH 上的目录。
   - 换替身：测通用启动函数、git 入口、git 夹具、自检记当前目录这四样的六组测试里，换模块函数的地方，改用替身模块。
   - 一处把内建模块名放在变量里再交给 `require` 的（观察文件、网络接口那组），改成两个字面量。
   写在字符串里、运行时落盘再跑的代码原样留着（ADR-219 第四节第三条）。
3. **闸门。** `TEST_ONLY_MODULES` 加 `child-process-stand-in`，三个名字；「测试文件」那一节不用加（需求测试已在里面）。登记表「待挪」清空。

## 四、拦不住的

- ADR-217 第三节、ADR-219 第四节、ADR-220 第四节、ADR-222 第四节写的那几类照旧：写在字符串里落盘再跑的代码（需求测试里就有几处起 git 的，CI 墙钟契约测试冻结的运行器也是）、拆开拼的模块名、经 `sh`、`npx` 之类转一手、不是 TypeScript 的脚本与工作流文件。
- 替身模块防的也是误伤：`withRestore` 交出的是被测代码换上的那个函数，它一般会再转给原函数；测试拿到它就能经它起进程。不交原函数挡的是「顺手存下来随便起」，不是存心绕。
- 替身模块那一句 `syncBuiltinESMExports` 没有变异守着：本仓库的测试都不按名字导入起进程的函数，测试里看不出差别（同 ADR-222 第四节最后一条）。它还会把别处换了内建模块的函数、却没同步的改动一起发布出去；现在换内建模块函数的几处都自己同步，没有影响。
- 交叠只在先了结的那一刻认得出：那之前两段已经在模块上叠着换了一会儿，起的进程走的是后一段的替身。拦下来的是「悄悄漏到后面」，不是交叠本身。
- git 入口、通用启动函数的文件头还写着「还没挪的见登记表」：这两份在观察器的设施清单里，改一个字节就要重新认证（ADR-221 第三节），本条不为一句文字去动它们；下一条为别的事改它们时一起改。
- 需求测试大小组里玩具仓库的环境：原先各组自己删六项或九项继承的 `GIT_*`，现在由夹具一律全删；成本、断网之类组外的变量照旧带着，git 不读它们。
