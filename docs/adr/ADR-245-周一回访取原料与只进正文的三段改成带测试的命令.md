## 一、改成什么

1. **取原料**（`--gather`）：两棵树都从 git 对象里读 `docs/adr/`，拿本跑这份代码打台账与被引表；不再建工作树、不再切目录跑两遍入口。六份文件（两份台账、两份被引表、新增、消失）写进给的目录，打一行「原料齐了 / 原料不齐：为什么」，不齐以 1 退出。不齐的四种照旧：一周前那棵树取不到、读不出、没打到末尾汇总、工作区的 `docs/adr/` 与本跑那棵树不同。
2. **(b) 第 1 步的增减**并进取原料：只比 `docs/adr/` 开头的行、去掉行号、按多重集合求差，与原来那段 awk 同一个算法。(b) 第 2 步往后一个字没动。
3. **(a)**（`--slow`）：例程取 `check.yml` 主干成功跑的接口返回、存成文件交进来；脚本按原来写在说明书里的口径算窗口、比值与工作量，条数从本地 git 取。
4. **(d)**（`--top`）：读取原料写下的两份被引表，打进了前十、掉出前十与两行汇总。前十按记录编号比。
5. **(e)**：`--never-red-pick` 从存下来的那几页挑本周那一跑与上一跑；`--never-red` 读两跑「清单」job 的日志与本周那一跑的 jobs，打两个验证者各一行与红了的整跑份数。
6. 交进来的文件先整份核形状（`process/3-BUILD.md` 第 9 条的「读时整份检查」），不对就以 2 退出、说哪一跑哪一样不对，不往下算。
   形状之外还核「是不是要的那一种」：(a) 的每一跑得是主干上 push 触发、跑完、成功的 `check.yml`；(e) 的每一跑得是主干上跑完的 `never-red.yml`；
   jobs 里每个 job 的 `run_id` 得是 `--run-id` 给的那一跑。取错了接口不悄悄算进去。
7. 接口不由脚本取：例程手头有什么 GitHub 工具用什么（说明书原来就这么写），脚本不联网，需求测试也就不用假造网络。
8. (a) 有一跑「前面不足 5 次」、而交进来的跑比页上 `total_count` 少，多打一行叫再取一页；(d) 被引表里认不出的 `docs/adr/` 行不悄悄跳过，多打一行说几行。

## 二、核过什么

- 取原料在真仓库上与原来那段 shell 逐字节比过：`--today 2026-11-23`，本跑 `96f197df`，一周前 `2184b12`，六份文件（两份台账、两份被引表、新增 610 行、消失 373 行）与 shell 打出的完全相同。
- 行为改了的一处：一周前那棵树原来用 `--before="<那天> 00:00 +0800"`，git 会把正好在 00:00 那一秒的提交也算进去；改成前一天 23:59:59，与说明书「00:00 之前」一致（提交时刻只到秒）。玩具仓库上有一例钉住。
- (a)、(e) 用的接口字段（`id`、`head_sha`、`created_at`、`run_started_at`、`updated_at`；jobs 的 `name`、`conclusion`）对照过主干上一跑 `check.yml` 的真返回；
  后加的「是不是要的那一种」用到的 `head_branch`、`status`、`path`、`event`、`conclusion`、`total_count` 与 jobs 的 `run_id` 照 GitHub 接口文档写，没再对一次真返回 —— 名字错了第一次回访就会以 2 退出、点名是哪一样，不会悄悄算错。`never-red.yml` 合入后还没跑完过一次（2026-11-24 查的），(e) 只在需求测试的假日志上跑过。
- 需求测试两组：`h-revisit-raw` 直接调判定（取原料在玩具仓库上问 git），`h-revisit-raw-entry` 在玩具仓库上真起五支入口。五十六条变异（M-H245-a 到 bd）逐条施加，点名的断言都红。

## 四、碰到的欠条

三个独立的清点把台账里每张开着的欠条与本改动比了一遍（2026-11-24）：

- 真响了的只有 ADR-151「周一那几段命令没有测试跑」，本条还上（第三节）。
- ADR-89 那张「变异只验点名的断言红」：本条新加的五十六条变异都点名了断言、逐条施加核过红，不另起；它本身照旧开着。
- 字面碰到、实质没碰的：ADR-151 里被引表与回访口径的几张、ADR-154、ADR-202、ADR-155、ADR-158（CI 上墙钟对比那一行与 (a) 是两份同口径的算法，本条只挪了 (a) 那一份进带测试的文件，两份会不会走样那张照旧开着）、
  ADR-167（ADR-151 主文件挪走一张欠条后行号往前挪了，它点的那一行另有锚点，没断）、ADR-198、ADR-86、ADR-232、ADR-70、ADR-220、ADR-212、ADR-222、ADR-211、ADR-236、ADR-81、ADR-99。
- ADR-203「主干只有墙钟、没有 CPU 时间」：(a) 照旧用墙钟判慢，本条没让它更坏也没还它，不响。

## 五、证不了的

- (a)、(e) 要例程自己把接口取全：翻页取到窗口起点之前至少 5 跑、取到上一跑。脚本看得出「交进来的跑里没有比本周那一跑更早的」，也看得出 (a) 交进来的比页上 `total_count` 少，都会叫再取一页；
  看不出的是例程存页时漏存了一页却把 `total_count` 也改小了这种手误 —— 照抄接口原样返回就不会有。
- 说明书里 (b) 第 4 步、「候选句」、「一块怎么写」仍是给人（例程）读的判法，不是命令，本条不管。
