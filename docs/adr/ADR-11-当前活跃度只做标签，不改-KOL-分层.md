# ADR-11 当前活跃度只做标签，不改 KOL 分层

- 日期 · 2026-08-26 · 停更账号处理
- 类型：**产品取舍**
- 冲击的需求：新增 D10，扩展 U7
- 结论：**采纳**

### 触发它的事实

累计作品数只能证明历史内容积累。一个发过数百条内容、曾经互动和带货都很好，但已经
停更一年的账号，仍会满足原来的 `post_count > 30` 加分。发布间隔也只描述过去的节奏，
不能回答“截至本次采样已经多久没有更新”。

这不是假粉或受众质量问题，而是当前合作就绪度。直接删除会损失历史高价值账号；继续把它
放在“活跃”口径里又会误导运营。

### 结论与边界

- 用样本时间减去最后发布时间，分为 active（≤45 天）、cooling（46–90 天）、
  dormant（>90 天）
- 标签按平台独立计算，仅展示，不改变 score、tier、风险或名单成员
- `post_count > 30` 的 +10 保留，但统一改称“内容积累”，不再声称它代表当前活跃
- 最近发布时间包含置顶作品；置顶只从绩效聚合中排除，不能抹掉一次真实发布
- 一个有效发布时间即可测量；缺失或异常时间明确 unavailable，不补默认值
- 活跃状态是采样时快照。旧样本可以零请求补算；需要确认现在是否复更时必须刷新样本

### 教训

**历史价值与当前可联系性是两条轴。** 把它们压成一个“活跃度”分数，要么误杀曾经有效的
创作者，要么把已经停更的人包装成随时可以合作。分别展示，才允许运营做真实取舍。
