## 一、为什么要管

信是发给博主本人的。说错了他做过的内容、给他安了一个他没说过的观点，他一眼就看得出来，等于证明「你没看过我」；信发出去收不回来。产品说法有 P2 管，写博主的话原来只有「第一句引用作品」一条。

## 二、决定

1. **并进红线 P2，不单开一条。** 卡上推荐的是单开一条普通需求（理由：写错博主伤的是回复率与观感，不像编造产品信息那样有法律风险），需求所有者选了并进红线：发出去收不回、伤的是用户的信誉，这一点两者一样。从此它和产品说法一样不参与任何取舍，强制的测试与变异要求也一并适用。
2. **管哪些句子。** 凡是在说博主是谁、做了什么、说了什么、他的内容怎样的句子，都要能指回他资料里的原文：原样引用，或准确改写（不加资料里没有的判断、动机、评价）。发件人自己的感受（「这条让我想到了我们的产品」）可以写，但不能借感受给博主安新说法（「你一直是最懂收纳的人」不行）。资料里没有的，不写，或者留 `{…}`。
3. **哪些资料算出处。** 只认博主自己写的文字：简介、最近作品的文案、昵称。Agent 评审里记的「观察内容」「作品证据」是 Agent 自己的话，拿它当出处等于自己给自己作证，不算。
4. **机器怎么查：Agent 登记，机器对账，人看改写。** Agent 写草稿时在评审正本那条评审里写 `creator_sources`：每句写博主的话一项，`draft` 是信里那一句（照抄），`from` 是 `bio`／`post`／`nickname`，`quote` 是资料里的原文片段；发件人自己的话写 `from: "self"`、不写 `quote`。render 在评审 HTML 的草稿块里单列一行「写博主的话出处：」，按在草稿里出现的先后逐条列：
   - 登记的原文在那一样资料里逐字出现（不分大小写、空白合并、弯直引号同等）：「信里这句」← 资料原文；
   - 原文在资料里找不到：同样写出，标「原文对不上」；
   - `self`：标「发件人自己的话」，让人确认没有借它安新说法；
   - 登记的那句已不在草稿里（草稿改过、登记没跟着改）：排最后标出；
   - 草稿里提到博主（you、your 一类词，昵称里三个字母以上的词，账号名）却没被任何登记覆盖的句子：标「没标出处」。Hi／Hello／Hey／Dear 开头的问候行不算。
   - 一条都没有写「无」。
5. **只标不拦。** 草稿一个字节都不改（P2.b），render 照常以 0 结束，CSV、XLSX 不加列。没有草稿或草稿只有空白、默认模式的旧 HTML 不出这一行（U9.a）。

## 三、为什么这回选「Agent 登记」，而 ADR-199 当时驳回了它

ADR-199 给产品说法选的是「机器扫字面形状」，驳回了「Agent 逐条登记出处」：产品说法里最危险的是数字和承诺词，有固定的字面形状，扫得出来。写博主的话没有这种形状 —— 准确改写和编造在字面上分不开，机器只能拿用词重合度去猜，误报漏报都多；开发信数字核对那条线（ADR-209）已经看到，靠字面规则猜，评审每轮都能找出新漏洞。登记之后，机器要回答的只剩「这段原文在不在」，是确定的问题；改写准不准交给人，报告把两边并排放，看一眼就够。

代价：评审正本多一个可选字段（旧评审没有它照常读，没有登记的句子会被标「没标出处」）；Agent 写信多一步。

## 四、实现者替需求所有者选的默认

合入即认；想改，合入前说一句即可。

1. **「提到博主」只认 you 一类词、昵称里三个字母以上的词和账号名。** 用 he／she／they 说博主的句子（信是写给他本人的，很少这样写）认不出来。重启条件：真实草稿里出现过这样描述博主、却没被列出的句子。
2. **按句切只认 . ! ? 后跟空白和换行。** 「Mr.」这类缩写会被切开，只影响列出来的那一段有多长，不会漏列。
3. **登记覆盖一句的口径：那一句包含登记的 `draft`，或登记的 `draft` 包含那一句。** 登记一句里的一小段也算这句登记过了。重启条件：发现 Agent 只登记一句里无关紧要的一小段来躲列出。
4. **`post` 不指定是哪一条作品，任一条作品文案里有就算。** 作品的 `id` 不总是有（D11），按下标指又会随续跑变。重启条件：运营要求在报告里看到是哪一条作品。

## 五、按改需求逐条评定

- 红线：P2 收紧 —— 管的范围从产品信息扩到写博主的话，原有的 P2.a、P2.b、P2.c 一句不改。登记里引用的博主原文只证明博主说过，不证明产品事实：产品说法照旧只认已证实的产品事实。P1、P3、P4、P5 不碰（不发请求、不碰记忆、不改费用）。
- 缩范围还是降标准：都不是。红线管得更宽，新加一层给人看的对照。
- 覆盖还是可信：可信上升 —— 写博主的话第一次有了可对照的出处。
- 可逆：可逆。正本字段可选，HTML 多一行，不改表格、不改退出码。
