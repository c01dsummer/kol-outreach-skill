## 二、检查怎么判

1. **一轮**：同一个版本上的全部行内意见，回复不算。同步主干的合并、空提交不起轮，锚在它们上面的意见算进它下面最近那个起轮的版本（含手写冲突解决的同步合并也一样折，见第四节）。没有意见的版本不算一轮，「连着」跳过它们。锚在已被强推掉的版本上的意见单独成一轮，按它最早一条意见的时间插进链上各轮之间。
2. **地方**：按第一节那几行换算。代码文件按顶层声明，不按最内层函数 —— 内层的帮手函数（`visit`、`walk` 这类）会把一处拆成几处、同名的还会撞在一起。语句前面的注释与空行算这条语句的；一条变量语句里落到哪个名字算哪个，落在它前面的注释上就整条语句的名字都算。顶层调用先剥掉 `await`、`void`、括号再取第一个字符串参数（测试文件里 `await group('…', …)` 每一组各算一处）。多行意见按整个行范围，跨两处的两处都算。
3. **拦**：相邻两轮有同一处 → 红，报出是哪一处、两轮各是哪个版本、各条意见的链接。**Markdown 文件只列出、不拦**（见下）。
4. **解除**：决策记录里一张固定格式的表，标题、表头一字不差（举例放在围栏里，围栏里的不算）：

   ```
   ## 同一处连着两轮：改设计

   | 同一处 | 旧做法最后一轮的提交 | 新做法写在哪 |
   |---|---|---|
   | `scripts/check/某某-rule.ts#某个函数` | 0a1b2c3 | 本记录第二节 |
   ```

   写了的那一处（按报出来的那一处一字不差地比：解除别处、或解除整份文件，不放走具体那一处），那个提交和它之前的轮次不再算；之后又连着两轮落回来，再红（`6-INTEGRATE.md`「又落回来,再停一次」）。表格式不对、提交不在这条 PR 的链上，那一行不算解除，报红。新做法是不是需求所有者定的、他看没看过，机器分不清，以他合入为准。

**Markdown 只列出、不拦**：需求所有者 2026-11-19 18:19（UTC）在选择卡上选「文档只列出不拦，代码照拦」。依据是复核按近 40 条已合入的 PR 估：评审多于一轮的 22 条里，按节算仍有 11 条会因为文档红（决策记录的节、术语表、同步表），拦了说明会变成走过场；#471 那种反复修补出在代码上。

## 三、在哪跑

只在 GitHub 上跑（`.github/workflows/same-spot.yml`）：要这条 PR 的评审意见，本地 `npm run check` 没有这份令牌，只跑它的测试。推送、评审、评审意见都触发，每条 PR 一组、新的一跑顶掉旧的，各种触发同一个任务名。权限只读。不放进 `check.yml`：那一份整份钉死在变异负载闸门里，权限也只给到读代码和读运行记录。

**要它真能拦住合入，需求所有者要在 main 的分支保护里把「同一处连着两轮」加成必须通过。** 这项设置不在仓库里，本条改不了。没加之前它只是一盏红灯。

## 四、拦不住的

- 改名、拆分、挪走以后的同一处；同一段做同一件事的代码跨了两个顶层声明、同一条规则的文字跨了两节。
- 只写在评审正文里的意见、替身评论、开 PR 之前的复核、被删掉的意见。
- 含手写冲突解决的同步合并照样折进上一轮，那次合并里改的东西上挑出的意见算进上一轮。
- 评审者在原线程里回复「还没修好」：回复不算新意见，不起轮、不拦。
- 变基或强推以后内容相同的新提交另起一轮；被推掉的旧版本取不到文件，那一轮的意见一律算整份文件（只会多报）。
- 取数入口只在 GitHub 上跑，它自己的几样（缺环境变量退出、翻页停在哪、有拦或有格式错就退出 1、取不到文件）没有断言、没有变异守着；判定那一半（分轮、换算地方、比较、解除、提交链、提交号定位）都在判定模块里、有测试与变异。
- 工作流检出 PR 头：合入时还开着、没同步主干的 PR 没有这个入口，一跑就红；来自分叉仓库的 PR 按提交号检出没实测过。三种事件各出一份同名结果，分支保护设成必须通过以后认的是哪一份，设之前要试一次。
- 需求所有者看没看过解除说明 —— 只以他合入为准。分支保护没加成必须通过时，红了也合得进去。
- 反过来多报的：一个大的顶层声明（一个几百行的函数）里两处不相干的毛病也算同一处；整份文件算的文件（json 等）任何两条都算同一处。多报当场红、有人看。

## 五、它替代什么、什么时候撤

**替代的是「跑」，不替代「读」**（`process/README.md` 第二层「一道闸门该不该建」）：位置、版本、语法树都是确切答案，同一份评审记录永远同一个结论。「这两条说的是不是同一件事」「新做法换对了没有」不碰，那一半是读，留在第三层。

> **什么条件下退成只报数**：连续二十条红过的 PR 里，没有一条是作者照常补完、合入后同一处又被挑出来的 —— 停手改设计已经成了习惯，红的只剩多报。
