# ADR-124 发现来源变异复用既有断言并接入需求测试分组

- 日期：2026-09-28
- 类型：发现更优解
- 起点：main `16714601fb378b474c1b6d8e90bf1911f62f14dd`；该目录为 771 条变异，实际路由为 691 条选组、80 条全跑。
- 结论：采用一个独立需求组容纳既有发现来源断言，先接入以下五条；不改变来源采集功能或业务验收标准。
- 依据：D15.c/d/h/i 与 ADR-110 的来源显示决定；验证及集成资格引用 `process/4-VERIFY.md`、`process/6-INTEGRATE.md`，路由边界引用 `docs/ARCHITECTURE.md`。

## 此次接入的边界

两个既有 D15 测试块以原顺序归入 `d15-discovery-sources`，无组依赖；输入与累加器在块内构造，
公共夹具函数只从给定参数产生数据。不删断言、认领或其它 D15 边界，不改业务函数或施变正文。
五条都用 `by: "test"` 与上述 `kills`；实际范围由具名断言归组推导，不写手抄 `only`。
完整测试仍运行所有块；正常子集、依赖、认领所有权及 worker 隔离沿用既有机制。

正常源码须先完整通过该组，再逐条确认指定断言确实失败；M-D15-i 的两个名字须都失败。
全跑与选跑对照只允许使用同一集合与正常基线合格的成功完整运行，耗时必须附范围与环境。
这份决定先公开对应关系，不表示接入、实测收益或十五分钟目标已经完成。

M-D15-e 暂不迁移：现有跨平台并集断言使用动态名字，尚未建立可登记的固定具名关系及明确主记录选择输入。
两条 U6 页面变异也继续全跑，现有静态字符串断言不替代实际切换可见性证据。
其它未接入条目照旧全跑；没有通过删变异或放宽故障、归因判定取得收益。

本分支从上述 main 独立开出，只改需求测试、变异目录与本记录及索引；与成本入口 PR224 的文件不重叠。
成本接线修好不计作本批迁移收益；后续结论须来自本批实际验收。
